#implementation #julia #experiment

> Experiment E-4 on Sophia's side: Julia's expansions of a package's module-level macro calls (printed by `expansions.jl`, [[expansions]]) spliced into the package in place of the forms and ingested like any source, so that methods made by `@eval` loops and macros get Sophia's ids; per method, whether the source as written, the expansion, or neither covers it; per expansion, a transformation record (SPEC-006 §6a) with an input address. Source: `expansion.rs`. Results: [[Semantic Boundary Experiments]] §E-4.
>
> Sources: [[SPEC-006 Worlds, Artifacts and Evidence]] §6a; [[Julia Macros and Generated Functions]] (option 2); [[Julia Conformance]] part 5 (the forms, `module_forms`). code: `expansion.rs`, `conformance.rs` (`module_forms`, `template_at`), `tests/expansions.rs`, `examples/julia_expansions.rs`

- **`parse_expansions`** reads `expansions.jl`'s output into `Expansion`s (one per record, with its methods and bindings); fields are unescaped (`\\`, `\n`, `\t`, `\r`).
- **`expansion_ledger(dir, tsv)`**:
  1. finds each form (file, line) among the module-level forms of Sophia's parse (`module_forms`, the same as part 5); a form on a line with another form, or in a file read into several modules, is not compared (`ambiguous`, `unmatched`);
  2. replaces each compared form's span by its records' texts, one after another, each on its own lines, and keeps each record's span in the new text;
  3. ingests the package as written and as expanded (`module::ingest`), naming each definition's function as part 5 does (`julia_scopes`, `julia_extends`);
  4. per method a record made: **Known** if a definition of the form as written (not an `@eval` template) covers it; else **OtherModule** if every covering definition of the record's text is in another module than the one Julia evaluated the record in (`@eval M ex`); **Recovered** if a covering definition has an id; **RecoveredRefused** if covering definitions exist but are refused (`detail` gives the reason); **Constructor** if a `struct` of the text has the name; **Unnamed** if the text has a function definition with an id and no name (Moonkale's naming gives `T{P}(…) = …` none, part 8); else **Open**. Record 0 (`rest`) methods are Known or Open.
  5. A definition **covers** a method of Julia's function `o` when it names `o`, a function with the same last name component (an alias, SP-013), a constructor of `o` (`T.new`), or, without a name, a callable object's method (`(::T)`). Matching is by function, not by signature: `@kwdef`'s keyword constructor covers the default constructors too.
- **Transformation records.** `by` is the macro's binding; for a macro the package defines, `by_id` is its definition's id and `by_text` the digest of its source text (most package macros have no id: a body that is a `quote` with `$` is refused); `input` is the digest of the form's source text; `template` and `parameters` are an eval record's template and splice values; `world` is Julia's version. **`address`** is a digest over these (canonical encoding, `sophia-hash`), computable before running the expansion; `text` and `output` (ids of the text's definitions) are what it produced. The template is in the address because several `@eval`s in one loop share the form and the values (on LinearAlgebra, without it 70 records shared an address with a different text).
- **`clashes`**: records whose address another record shares with a different text, E-4's failure condition. It catches what `stable` cannot: state that changed between two identical calls (the fixture's `@stateful`; [[Review 2026-11-19 Codex B-025 (external)]] 1). LinearAlgebra: none.
- **`faithful(expansions, macros)`**: per form with records, whether the methods its records made have the same owners, with multiplicity, as those `macros.jl` lists for the form as written ([[macros]]).

`owners` (Sophia's definitions of a package with their functions and ids, and the ingest itself) is shared with E-5 ([[derivative]]).

What it does not do: store anything. The records are computed, not written to a store; a table for transformation records is a storage change that needs Daniel's agreement (SR-126). It does not run Julia; the oracle's output is its input. It compares methods by function name, not by signature.
