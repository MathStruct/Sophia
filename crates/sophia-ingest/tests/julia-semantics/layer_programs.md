#implementation #julia #experiment

> The Julia side of experiment E-6 (one derivative, two layers): for each function of the E-5 fixture's `base` variant and an argument type, the derived program of its gradient at **Julia IR** (Zygote, printed by [[derivatives]]'s functions in this process) and at **LLVM IR** (the module Enzyme builds), and both gradients at ten points against a 512-bit reference. Source: `layer_programs.jl`.
>
> Sources: Enzyme 0.13.216 `src/compiler/reflection.jl` (`enzyme_code_llvm`, which compiles the job, links the module's Julia values as Enzyme's thunk does, and runs the second optimisation stage), `ext`'s of EnzymeCore 0.8.26 (`EnzymeCoreChainRulesCoreExt`); Zygote 0.7.18; Julia 1.12.7 (`unsafe_pointer_to_objref`, `Base.StackTraces.lookup`, `jl_value_ptr`). code: `layer_programs.jl`, `layers/` (environment and outputs), `derivatives.jl` ([[derivatives]]), `src/layers.rs` ([[layers]]), `tests/layers.rs`, `examples/julia_layers.rs` ([[julia_layers]])

```sh
# from crates/sophia-ingest/tests/julia-semantics, inside `nix develop`
julia112 --project=layers layer_programs.jl rules/variants/base > layers/truth.tsv
julia112 --project=layers layer_programs.jl rules/variants/base reverse | grep -E '^(julia|package|enzyme)\b' > layers/reverse.tsv
```

(`nix develop` prints a banner on stdout; remove its line from the output.)

- **Environment.** `layers/Project.toml` is `rules/Project.toml` plus Enzyme, resolved offline with Julia 1.12.7: Zygote, ChainRules, ChainRulesCore and IRTools keep E-5's versions; Enzyme 0.13.216 and EnzymeCore 0.8.26 are the versions `experiments/ad-materialization` uses. LLVM is Julia's own (18.1.7).
- **Zygote's side** is E-5's: `layer_programs.jl` includes `derivatives.jl` (which loads the variant from `ARGS[1]`; run as a script it prints everything, included it only defines) and calls its `tables` and `rows`. Its lines are E-5's (`table`, `rule`, `derived`, `instance`, `piece`), printed with Enzyme loaded.
- **Enzyme's side**, per function and type: the first `autodiff(Reverse, f, Active, Active(x))` (timed: Enzyme's transformation, compiling, one run), then `enzyme_code_llvm(io, f, Active, Tuple{Active{T}}; debuginfo = :none, dump_module = true)` (timed): the whole module with the derivative and everything it calls. A gradient Enzyme refuses is `refused:` and the exception's type (`dyn`: `NonInferredActiveReturn`, its return type is not inferred).
- **The module text is normalised**, because as printed it depends on the session:
  - **addresses**: Julia's code generator embeds pointers as decimal literals. Only literals in a **pointer position** are read (an integer constant elsewhere is data): an `inttoptr (i64 N to ptr)` value, a type tag (`store atomic i64 N, ptr %"….tag_addr"`, the last argument of `@ijl_gc_…alloc…(…, i64 N)`), an `enzymejl_mi`, `enzymejl_rt` or `enzymejl_parmtype` attribute. Each is a Julia object and is replaced by what it is: `{type Float64}`, `{mi Tuple{typeof(sin), Float64}}`, `{String "sin(x) is only defined for finite x."}`, `{fn typeof(f)}` for a function without state. An object with state (a closure's captures, a struct) becomes `{obj T repr}`, which tells two apart but may depend on the session; it is not counted as named. A call through an address (`inttoptr (i64 N to ptr)(…)`) jumps to native code, not to an object; it is named by Julia's symbol lookup (`{code ijl_box_float32}`) or, when the lookup has no name, left as its number. Dereferencing that one as an object crashed the first version of the script; reading any number in the address range as a pointer was finding 1 of [[Review 2026-11-19 Codex B-027 (external)]];
  - **session numbers**: in names only (global `@julia_sin_12951`, `@diffejulia_f1_10492wrap`; local and block labels named after an inlined callee, `%diffejulia_p_25490.exit`, and the label's definition), renumbered by first appearance in the module (`julia_sin_#1`). A string constant that spells such a name is data and stays.
  The `enzyme` line counts the distinct addresses in pointer positions and how many were named. At start the script asserts the normaliser on synthetic text for each of the review's findings 1 to 4 and 8.
- **Agreement**: at ten points (0.1, 0.35, 0.7, 1.3, 1.9, 2.6, 3.4, −0.45, −1.7, 5.2, converted to `T`), Zygote's gradient, Enzyme's, and a central difference of f at the same input in 512-bit BigFloat with h = 2⁻¹²⁰ (the fixture's functions are generic, so f runs on BigFloat unchanged).
- **`reverse`** as the second argument runs the Enzyme rows in the opposite order: the same inputs after another session history, to test that the normalised text does not depend on it.
- **Output lines**, besides `derivatives.jl`'s: `julia`; `package` for Zygote, ChainRulesCore, ChainRules, IRTools, Enzyme, EnzymeCore, and `LLVM`; `enzyme label target type status ns_first ns_export raw_bytes raw_digest addresses named bytes digest`; `point label target type x zygote enzyme reference` (`repr` of each value; `-` where Enzyme refused); at the end each normalised module once, `module digest text` (escaped as `piece`).

**Checked (2026-11-19):** runs in separate processes, in order and reversed: normalised modules identical, raw texts different in all 18 under the reversed order (before the review's fixes, two runs in the same order also gave identical raw texts: the same history allocates alike). Every address in a pointer position named (7 or 11 in the modules that reach `sin`, 2 for `exp`, 1 for `p`, `q`), no session number left. With Enzyme loaded, Zygote's `derived`, `instance` and `rule` rows are E-5's (`rules/truth.tsv`, label `base`); the `rrule` and `frule` tables each have one method more (`ignore_derivatives`, from `EnzymeCoreChainRulesCoreExt`). `derivatives.jl` run as a script after the change (with the session file) gives E-5's `base` and `base+session` rows exactly, timings aside.
