Ordinary theorem bodies take the synchronous path with `Elab.async=false`. I verified the separate replay path in the installed source, but did not measure its cost in the 60-file run. **Fix:** before stopping the timer, join the command’s checked environment and drain its snapshot tasks. 4. **Verified in source: the error counter can report zero for a failed command.** `elabCommandTopLevel` clears messages for each command.
