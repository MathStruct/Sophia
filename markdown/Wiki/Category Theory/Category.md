# Category

A category consists of a collection of **objects** and, between any two objects, a collection of **morphisms** (arrows), together with an associative operation for **composing** morphisms and an **identity** morphism on every object. That's the entire definition — no notion of "elements inside an object" is required.

Examples relevant here: **Set** (objects are sets, morphisms are functions), **Type** in a given programming language (objects are types, morphisms are functions between them — see [[Category Theory and Programming Languages]]), and a category built directly from an AST or graph (objects are nodes, morphisms are the paths/edges between them, composition is path concatenation). A graph database storing code is, structurally, already close to the free category generated by its edges.
